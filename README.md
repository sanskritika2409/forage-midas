# 💼 Forage MIDAS — JPMorgan Chase Software Engineering Simulation

> Completed as part of the **JPMorgan Chase & Co. Advanced Software Engineering** virtual experience on Forage

---

## 🧠 What is this?

This project was completed during the **JPMorgan Chase Advanced Software Engineering Virtual Internship** on Forage. It involves working on a real-world style codebase to fix bugs, interface with financial data systems, and build features as a software engineer at JPMC would.

---

## ✨ What I did

- ✅ Set up a local dev environment and fixed broken repository code
- ✅ Interfaced with a stock price data feed to output correct data
- ✅ Used JPMorgan's open-source **Perspective** library to create a live financial data graph
- ✅ Worked with real engineering tasks simulating a JPMC SWE role

---

## 🚀 Getting Started

### Prerequisites
- Java JDK 11+
- Node.js (for Perspective visualization)

### Run locally

```bash
# Clone the repo
git clone https://github.com/sanskritika2409/forage-midas.git
cd forage-midas

# Install dependencies
npm install

# Start the server
npm start
```
